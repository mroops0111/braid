# `@braidhq/desktop`

Tauri 2 shell that wraps `@braidhq/studio` (UI) and a Node sidecar running
`@braidhq/server`. The shell ships as a single Mac / Windows / Linux app so
non-technical users can run Braid by double-clicking the installer.

This package has no TypeScript sources of its own. The frontend lives in
`@braidhq/studio`; the backend lives in `@braidhq/server`; this package
glues them together via Tauri config and a small Rust entry point.

## Layout

```
packages/desktop/
  package.json                # scripts: dev, bundle, prepare-sidecar, test
  scripts/
    prepare-sidecar.mjs       # rebuilds + stages the sidecar resources
    lib/platform.mjs          # pure helpers: Rust target + Node tarball mapping
  test/scripts/               # vitest unit tests for the pure helpers
  src-tauri/
    Cargo.toml                # crate `braid-desktop`
    tauri.conf.json           # window, externalBin, resources
    capabilities/default.json # core + scoped shell:allow-execute for the sidecar
    src/
      main.rs                 # Windows console suppression + entry
      lib.rs                  # spawn / track / kill the Node sidecar
    icons/                    # platform icons generated by `tauri icon`
    binaries/                 # node-<rust-triple> (gitignored, downloaded)
    resources/server/         # copied bundle (gitignored, regenerated)
```

## Build chain

```
@braidhq/server build
   ↓ tsc -p tsconfig.json
@braidhq/server bundle
   ↓ esbuild + copy kuzu prebuilt + trimmed package.json
@braidhq/desktop prepare-sidecar
   ↓ rerun the two above, copy bundle into resources/, download Node binary
tauri dev / tauri build
   ↓ compile Rust, embed externalBin + resources, run or package
```

`prepare-sidecar` runs automatically before `tauri dev` and `tauri build`
via `beforeDevCommand` / `beforeBuildCommand` in `tauri.conf.json`.

## Local development

```sh
# One terminal: builds the Rust crate, downloads Node sidecar on first run,
# starts vite for the UI, opens a window with HMR.
pnpm --filter @braidhq/desktop dev
```

The first invocation takes a couple of minutes (Rust cold compile, Node
download). Subsequent runs reuse cached artifacts and start in seconds.

## Production installer

```sh
pnpm --filter @braidhq/desktop bundle
# Outputs under packages/desktop/src-tauri/target/release/bundle/
```

The bundle target defaults to the host triple. Cross-target builds set
`BRAID_RUST_TARGET` (Tauri) and `BRAID_BUNDLE_TARGET` (server). Both are
covered by the helper tests under `test/scripts/`.

## Server URL resolution at runtime

Studio resolves its API base URL in this order (see
`packages/studio/src/lib/serverUrl.ts`):

1. `localStorage` override set via the in-app dialog. Lets Tier 2/3 users
   point the same binary at a remote team server.
2. Embedded sidecar URL, obtained via the `get_server_info` Tauri command.
3. `VITE_BRAID_API_URL` env var.
4. The hard default `http://localhost:4321` (used by the dev server).
