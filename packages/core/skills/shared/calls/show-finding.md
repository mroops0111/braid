# `show_finding`

Use it whenever two sources agree, disagree, or cannot be checked against each other. One finding per statement, so a block carrying three disagreements is three blocks, and name both sides rather than picking one.

**Look before you answer.** The nodes involved carry `metadata.driftIssues`, and a workspace that has been reconciled holds dozens. Reporting a known drift as new spends a reviewer's time on something already triaged.

The response says which reading the surface derived from your sides, so read it back. A finding the reader will see marked `thin` should not be narrated as settled, and the way to strengthen it is to find the missing reference and send the finding again, never to write around the gap.
