# `show_finding`

One consistency statement. Use it whenever two sources agree, disagree, or cannot be checked against each other.

Name both sides, never pick one. One finding per statement, so a block carrying three disagreements is three blocks.

**Look before you answer.** The nodes involved carry `metadata.driftIssues`, and a workspace that has been reconciled holds dozens. Reporting a known drift as new spends a reviewer's time on something already triaged.

Never assert how well the evidence carries a finding. The surface derives that from the sides and the response says which reading it came to, so read it back. A finding the reader will see marked `thin` should not be narrated as settled, and the way to strengthen it is to find the missing reference and send the finding again, never to write around the gap.

`unverifiable` is a real answer. A run that could not settle a question says so rather than choosing the side it read most recently.
